# UAE Trip AI
A visual, mobile-first UAE travel planner prototype.

## Run
Open this folder in VS Code and open `index.html` with Live Server, or double-click `index.html`.

## Features
- Real UAE attraction names and areas
- Visual place cards
- Real restaurant references for Old Dubai
- Food guide
- 7-day area-based itinerary
- Google Maps deep links
- Family-focused planning logic
- Responsive mobile UI
- Light/dark mode
- PWA manifest

The image URLs and Maps links are external. For a production app, replace them with licensed/local assets and connect live Maps, transport, opening-hours and reservation APIs.
